# JEE PULSE
Track. Test. Improve. Repeat.

Installable web app (PWA) for JEE preparation: tests, results, syllabus, analytics, mistake book, study records, goals, calendar, daily quotes. Works offline; all data stays in your browser (IndexedDB).

## Deploy on GitHub Pages
Upload every file in this folder to the repository root (`index.html` must be at the top level), then Settings > Pages > Branch `main` / `/ (root)`.

## Install on phone
Open the site in Chrome (Android) or Safari (iPhone), then Install app / Add to Home Screen.

## Backup
Settings > Export JSON. Backups contain all records; attached photos/files stay on the device only.
